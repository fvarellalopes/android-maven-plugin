== ANDROID MAVEN PLUGIN

image:https://img.shields.io/maven-central/v/com.simpligility.maven.plugins/android-maven-plugin.svg?label=Maven%20Central["Build Status", link="https://search.maven.org/search?q=g:%22com.simpligility.maven.plugins%22%20AND%20a:%22android-maven-plugin%22"]

A comprehensive Maven plugin for Android application development with http://maven.apache.org[Apache Maven 3.0.5+] and
the http://tools.android.com[Android SDK].

=== Quick Start

Add the plugin to your `pom.xml`:

[source,xml]
----
<plugin>
    <groupId>com.simpligility.maven.plugins</groupId>
    <artifactId>android-maven-plugin</artifactId>
    <version>4.6.1</version>
    <extensions>true</extensions>
</plugin>
----

See the link:docs/getting-started.md[Getting Started Guide] for complete setup instructions.

=== Features

The Android Maven Plugin provides:

* ✅ Complete Android project lifecycle management
* 📦 APK building and packaging
* 📱 Device deployment and testing
* 🔧 NDK compilation support
* 📊 Code coverage and static analysis
* 🎮 Emulator management
* 🐒 UI testing with Monkey and UIAutomator
* 🔒 ProGuard integration
* 📈 Lint analysis
* And much more!
